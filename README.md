# 🌿 Làng Sinh Viên Đổi Mới Sáng Tạo Bình Mỹ

> **Website giới thiệu hệ sinh thái Đào tạo – Nghiên cứu – Đổi mới sáng tạo – Y tế cộng đồng – Du lịch & Nông nghiệp bền vững.**

---

## 📌 Giới Thiệu Dự Án

**Làng Sinh Viên Đổi Mới Sáng Tạo Bình Mỹ** là mô hình campus mở, kết nối nhà trường, bệnh viện, bác sĩ, nhà khoa học, doanh nghiệp và cộng đồng trong đào tạo nhân lực, phát triển dự án y tế, nghiên cứu ứng dụng và đổi mới sáng tạo.

### 🌟 5 Trụ Cột Hoạt Động Chính:
1. **Ba mô hình y tế**: 
   - Trung tâm Y tế cộng đồng và Living Lab
   - Trung tâm Chăm sóc người cao tuổi
   - Trung tâm Health & Wellness (Wellness Farm, phục hồi sức khỏe)
2. **Đào tạo nhân lực y tế**: Đào tạo theo đơn đặt hàng, thực hành Living Lab, y tế số, ngoại ngữ chuyên ngành.
3. **Tư vấn phát triển dự án**: 3 dự án y tế trụ cột và 12 mô hình kinh tế phụ trợ (Nông nghiệp tuần hoàn, OCOP Bình Mỹ Xanh, Edu Farm...).
4. **Hợp tác quốc tế**: Trao đổi học thuật, hội thảo quốc tế, nghiên cứu đa trung tâm.
5. **Bác sĩ xuyên biên giới (*Doctors Across Borders*)**: Mạng lưới bác sĩ và chuyên gia y tế toàn cầu giảng dạy, hội chẩn, cố vấn và vì cộng đồng.

## 🚀 Công Nghệ Sử Dụng

- **Frontend Core**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Tính năng mở rộng**: 
  - Hỗ trợ đa ngôn ngữ Song ngữ VI | EN (Context API)
  - Tìm kiếm toàn trang (Quick Search Modal)
  - Modal đăng ký đề xuất hợp tác trực tuyến
  - Responsive mượt mà trên mọi thiết bị (Desktop & Mobile)

## 💻 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

```bash
# 1. Clone repository về máy
git clone https://github.com/khanhphamvn222/web2.git

# 2. Di chuyển vào thư mục dự án
cd web2

# 3. Cài đặt các gói thư viện phụ thuộc
npm install

# 4. Khởi chạy dev server
npm run dev
```

Trang web sẽ chạy tại địa chỉ: `http://localhost:5173/`
